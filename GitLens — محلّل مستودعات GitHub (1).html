الصلاحيات الصحيحة للـ Personal Access Token
اختر بدقة — لا تمنح أكثر مما يحتاجه التطبيق
ℹ️
Token الكلاسيكي (Classic) — اذهب إلى Settings → Developer settings → Personal access tokens → Tokens (classic) ثم اختر الصلاحيات التالية:
الـ Scope لماذا؟ مطلوب
repo (كامل) قراءة المستودعات الخاصة (Private repos) بالكامل — الكود والملفات والـ branches ✓ نعم
public_repo قراءة المستودعات العامة فقط — إذا أردت أخف صلاحية اختياري
read:org معرفة المنظمات التي ينتمي إليها المستخدم وقراءة مستودعاتها اختياري
repo:status قراءة حالة الـ commits — مضمّن في repo مضمّن
write:repo_hook تعديل — لا تحتاجه أبداً ✗ لا
delete_repo خطير جداً — لا تحتاجه ✗ لا
admin:org إدارة المنظمات — لا تحتاجه ✗ لا
⚠️
Fine-grained Token (الأحدث والأكثر أماناً):
اختر Repository permissions ← Contents: Read-only · Metadata: Read-only · Traffic: Read-only (لإحصائيات الزيارات). هذا النوع يقيّد الصلاحية على مستودعات محددة فقط.
